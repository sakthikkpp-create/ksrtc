# 🚌 KSRTC-SWIFT Redesign — Interactive Concept Prototypes

An exploration of 6 modern UX/UI concepts designed to revolutionize digital ticketing and bus travel experiences for Kerala State Road Transport Corporation (**KSRTC-SWIFT**).

## 🌟 The 6 Showcase Concepts

1. **Concept 1: Journey Planner** (`concepts/concept1-journey-planner.html`)
   - Visual route visualizer, multi-modal search, seat selection preview, and clean modern ticketing.
2. **Concept 2: Trusted Companion** (`concepts/concept2-trusted-companion.html`)
   - High accessibility, empathetic micro-copy, clear fares, and regional Kerala aesthetic.
3. **Concept 3: Kerala Darshan** (`concepts/concept3-kerala-darshan.html`)
   - Tourism & heritage-centric discovery, scenic route photography, and experiential travel packages.
4. **Concept 4: Power User** (`concepts/concept4-power-user.html`)
   - Dense informational layout, rapid keyboard shortcuts, multi-bus comparison matrix, and real-time transit telemetry.
5. **Concept 5: Hybrid Experience** (`concepts/concept5-hybrid-experience.html`)
   - Mobile-first adaptive layout with desktop power-grid switching and fluid micro-interactions.
6. **Concept 6: Minimalist Transformer** (`concepts/concept6-minimalist-transformer.html`)
   - Distraction-free booking flow, ultra-fast performance, and high-contrast night/day modes.

## 🚀 Deploying to Vercel

This repository is pre-configured for instant deployment on [Vercel](https://vercel.com):

1. Go to [vercel.com/new](https://vercel.com/new).
2. Import this repository (`sakthikkpp-create/ksrtc`).
3. Vercel automatically detects the static configuration with `vercel.json`.
4. Click **Deploy**.

The showcase gallery and all 6 concept pages will be live with clean URLs and optimized headers.

---

## 💻 Local Development

You can run the project locally using Node.js:

```bash
# Start the local showcase server
npm start
```
This automatically spins up a local server at `http://localhost:3000` and opens your browser to the Master Showcase Gallery.

Alternatively, open `index.html` directly in any web browser.
